## Comando principale

Quando vuoi iniziare una sessione operativa, usa:

**JARVIS START**

Quando vuoi concentrarti sul denaro:

**MONEY MODE**

## Filosofia

**Build → Use → Measure → Improve**

JARVIS deve produrre almeno uno di questi risultati:

- ricavi
- opportunità
- tempo risparmiato
- conoscenza riutilizzabile
- processi migliori
- decisioni migliori
