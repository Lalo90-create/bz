# BZ — CRM Pipeline

Use these stages for every commercial opportunity.

1. New Lead
2. Qualified
3. Contacted
4. Replied
5. Discovery / Meeting
6. Proposal
7. Negotiation
8. Won
9. Lost
10. Nurture / Follow-up later

## Minimum fields
- Lead / company
- Segment
- Location
- Contact person / role
- Problem / opportunity
- Best BZ offer
- Stage
- Priority score
- Estimated value
- Last contact date
- Next action
- Follow-up date
- Notes

## JARVIS rule
No active lead should exist without a clear **next action**.

## Weekly pipeline questions
- Which lead is closest to revenue?
- Which lead has gone cold?
- Which proposal needs follow-up?
- Which segment is responding best?
- Which offer is easiest to sell?
- Where are we losing opportunities?
