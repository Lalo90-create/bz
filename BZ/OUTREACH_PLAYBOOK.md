# BZ — Outreach Playbook

Goal: start relevant conversations, not spam.

## First-contact structure
1. Show relevance — why this company/person was selected.
2. Mention one plausible problem/opportunity.
3. Connect it to one clear BZ capability.
4. Ask for a small next step.

## Example framework
- Observation: "I noticed..."
- Relevance: "We work on..."
- Value: "We may be able to help with..."
- CTA: "Would a short 15-minute call make sense?"

## Channels
Prioritize according to the lead:
- email;
- LinkedIn;
- phone;
- referral/introduction;
- in-person local networking.

## Follow-up cadence
- Follow-up 1: short reminder + value point
- Follow-up 2: add one useful idea / observation
- Follow-up 3: close the loop politely

Do not send repetitive generic messages.

## JARVIS rule
Every outreach message should be personalized around the lead's likely business need, not around BZ's desire to sell.

## Approval rule
Prepare messages first. Human approval before sending externally unless the user has explicitly authorized an automation.
