# BZ Consulting — Offer Architecture

This file defines what BZ Consulting can sell in a simple, client-friendly way.

Bazinga Lab/CSC services live separately in `BAZINGA/OFFERS.md`.

## Offer 1 — Discovery / Audit
Goal: understand the client's current setup, problem and opportunity.

Typical outputs:
- needs assessment;
- current-state review;
- priority problems;
- recommended solution path;
- indicative scope and next steps.

## Offer 2 — Solution Design
Goal: turn a business/cultivation need into a concrete project.

Possible components:
- greenhouse / indoor layout;
- hydroponic system choice;
- lighting concept;
- climate-control concept;
- sensors / automation requirements;
- equipment list;
- implementation roadmap.

## Offer 3 — Equipment & Sourcing
Goal: source required equipment through BZ's supplier/partner network.

Possible categories:
- greenhouse structures;
- hydroponic systems;
- grow-room equipment;
- LED lighting;
- climate systems;
- sensors / IoT;
- irrigation and control systems.

Final prices and supplier conditions belong in private commercial records, not this public repository.

## Offer 4 — Implementation Support
Goal: help the client move from purchase to working installation.

Possible services:
- supplier coordination;
- logistics coordination;
- installation planning;
- local partner coordination;
- setup checklist;
- commissioning support.

## Offer 5 — Training & Optimization
Goal: help the client use the system correctly and improve operations.

Possible services:
- team training;
- operating procedures;
- process review;
- technology adoption;
- optimization sessions.

## Offer 6 — Partnership / Referral
Goal: create scalable relationships with installers, distributors, technology vendors and complementary professionals.

Possible formats:
- referral agreement;
- reseller relationship;
- project collaboration;
- local installation partner;
- co-selling / co-delivery.

# Commercial rule
Whenever possible, JARVIS should package BZ Consulting proposals as:

**Entry audit → Core project → Implementation / recurring optimization**
