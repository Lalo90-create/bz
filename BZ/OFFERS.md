# BZ — Offer Architecture

This file defines what BZ can sell in a simple, client-friendly way.

## Offer 1 — Discovery / Audit
**Goal:** understand the client's current setup, problem and opportunity.

Typical outputs:
- needs assessment;
- current-state review;
- priority problems;
- recommended solution path;
- indicative scope and next steps.

Use when the client is interested but the project is still unclear.

## Offer 2 — Solution Design
**Goal:** turn a business/cultivation need into a concrete project.

Possible components:
- greenhouse / indoor layout;
- hydroponic system choice;
- lighting concept;
- climate-control concept;
- sensors / automation requirements;
- equipment list;
- implementation roadmap.

## Offer 3 — Equipment & Sourcing
**Goal:** source the required equipment through BZ's supplier/partner network.

Possible categories:
- greenhouse structures;
- hydroponic systems;
- grow-room equipment;
- LED lighting;
- climate systems;
- sensors / IoT;
- irrigation and control systems.

Final prices and supplier conditions belong in private commercial records, not this public repository.

## Offer 4 — Implementation Support
**Goal:** help the client move from purchase to working installation.

Possible services:
- supplier coordination;
- logistics coordination;
- installation planning;
- local partner coordination;
- setup checklist;
- commissioning support.

## Offer 5 — Training & Optimization
**Goal:** help the client use the system correctly and improve operations.

Possible services:
- team training;
- operating procedures;
- process review;
- technology adoption;
- optimization sessions.

## Offer 6 — BZ Club / Professional Services
For legally compliant businesses and associations where relevant, BZ may provide non-plant-touching professional services such as:
- operational consulting;
- technology consulting;
- menu/communication support;
- staff education;
- quality/process review;
- vendor and technology research.

Any regulated activity must be checked against the applicable law before execution.

# Commercial rule
Whenever possible, JARVIS should package proposals as:

**Entry offer → Core project → Follow-on / recurring service.**

Example:
Audit → Solution Design / Equipment → Training / Optimization.
