# BZ — Money Database

This file is the commercial decision table for JARVIS.

It does NOT contain confidential prices, client names, private supplier terms or personal data because this repository is public.

## Opportunity score
For every idea, lead or project, JARVIS should score:

- Revenue potential: 1–5
- Probability of closing: 1–5
- Speed to cash: 1–5
- Time required: 1–5 (5 = little time)
- Cost to pursue: 1–5 (5 = low cost)
- Scalability / repeatability: 1–5
- Strategic fit with BZ: 1–5

### Simple score
Add the seven values.
Maximum: 35.

Interpretation:
- 29–35 = PRIORITY NOW
- 23–28 = STRONG OPPORTUNITY
- 17–22 = TEST CHEAPLY
- 11–16 = LOW PRIORITY
- 7–10 = IGNORE FOR NOW

## Revenue lanes
JARVIS should try to create opportunities in these lanes:

### Lane A — Fast cash
Small paid audits, consulting sessions, training, technical reviews, sourcing support, introductions or clearly scoped professional services.

### Lane B — Core projects
System design, equipment sourcing, greenhouse / indoor / hydroponic projects, implementation support.

### Lane C — Recurring value
Training, optimization, supplier support, periodic consulting, process reviews, ongoing commercial/technical assistance.

### Lane D — Partnerships
Referral agreements, reseller relationships, local installer partnerships, technology partners and complementary service providers.

## Money rule
Whenever JARVIS finds an interesting activity, ask:

1. What can we sell?
2. Who can buy it?
3. Why now?
4. What is the smallest paid step?
5. How quickly can we test demand?
6. What would make this repeatable?

## Weekly commercial review
At least once per week, review:
- qualified leads created;
- conversations started;
- meetings booked;
- proposals prepared;
- proposals sent;
- estimated pipeline value;
- revenue closed;
- best-performing offer;
- biggest blocker.

## Private layer placeholders
Keep the following outside this public repository:
- real customer names and contacts;
- exact commercial margins;
- private supplier pricing;
- bank/payment information;
- unpublished proposals;
- negotiation notes;
- sensitive legal/business documents.
