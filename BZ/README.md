# BZ Knowledge Base

This folder is the public-safe commercial brain of JARVIS for BZ.

## Read in this order
1. `COMPANY.md` — what BZ is and how it should be positioned
2. `OFFERS.md` — what BZ can sell
3. `TARGET_CLIENTS.md` — who BZ should sell to
4. `MONEY_DATABASE.md` — how JARVIS prioritizes opportunities
5. `PRIVATE_DATA_RULES.md` — what must never be stored publicly

## Operating loop

**Target → Problem → Offer → Lead → Qualification → Proposal → Follow-up → Revenue → Learn**

## JARVIS command
When the user says **BZ MONEY MODE**, use this folder together with the JARVIS Money Engine and Sales Engine.

Output should focus on:
- best commercial opportunity now;
- why it has priority;
- concrete next action;
- expected business value;
- what information is missing;
- what can be standardized or automated after the test.
