# BZ Knowledge Base

This folder is the public-safe commercial brain of JARVIS for BZ Consulting.

## Read in this order
1. `COMPANY.md` — what BZ is and how it should be positioned
2. `OFFERS.md` — what BZ can sell
3. `TARGET_CLIENTS.md` — who BZ should sell to
4. `LEAD_QUALIFICATION.md` — how to qualify opportunities
5. `CRM_PIPELINE.md` — how leads move through the funnel
6. `OUTREACH_PLAYBOOK.md` — how to approach prospects
7. `PROPOSAL_TEMPLATE.md` — how to structure proposals
8. `PRIVATE_DATA_RULES.md` — what must never be stored publicly

## Operating loop

**Target → Problem → Offer → Lead → Qualification → Proposal → Follow-up → Revenue → Learn**

## Global market logic
BZ operates globally.

Default execution ladder:
**Mazarrón / Cartagena / Murcia → Spain → Europe → international markets.**

This is a launch sequence, not a restriction. Stronger opportunities elsewhere can take priority.

## JARVIS command
When the user says **BZ MONEY MODE**, use this folder together with the central JARVIS Money Engine and Sales Engine.

Output should focus on:
- best commercial opportunity now;
- market / country;
- why it has priority;
- concrete next action;
- expected business value;
- what information is missing;
- what can be standardized or automated after the test.

## Architecture rule
There is only one central scoring system: `JARVIS/MONEY_ENGINE.md`.
Do not create a second BZ-specific copy of the same scoring logic.
