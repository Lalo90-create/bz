# BZ — Private Data Rules

This repository is public.

## Never store here
- client names with private contact details;
- personal phone numbers or emails not already public;
- passwords, API keys or credentials;
- exact private supplier pricing;
- unpublished margins or negotiation positions;
- contracts, tax documents or IDs;
- confidential proposals;
- banking or payment information;
- internal legal advice;
- sensitive operational notes.

## Safe to store here
- generic workflows;
- public company positioning;
- public-safe offer structures;
- generic target-client categories;
- scoring frameworks;
- reusable prompts;
- sales methodology;
- learning notes;
- non-confidential templates.

## JARVIS rule
Before saving new knowledge to this repository, classify it as:

**PUBLIC-SAFE** — can be stored here.

**PRIVATE** — must stay in a private workspace or private repository.

When unsure, treat it as PRIVATE.
