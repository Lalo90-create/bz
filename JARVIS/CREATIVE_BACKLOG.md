## Operating decision — integrated creative stack

The BZ creative department operates as one coordinated production system rather than as separate tool silos.

- **JARVIS / ChatGPT** — creative direction, research, concepting, copy, scripts, storyboards, prompting, orchestration, asset planning, QA and production-state management.
- **Built-in image generation** — raw scenes, concept art, supporting visuals, image edits and rapid visual exploration.
- **Runway** — use every connected capability that materially improves visual/video work: image generation/editing, image-to-video/video generation when the connected workspace supports it, B-roll, motion, cleanup, reframing and related production functions. Never assume a capability is available; verify the live workspace first.
- **Canva** — deterministic editable assembly, exact copy, approved-logo placement, layout systems, reusable components and final social-format compositing when supported by the connected design.
- **Web/reference research** — current visual references, platform behavior, technical source validation and trend checks when freshness matters.
- **Google Drive** — canonical private asset library.
- **Control Center** — canonical status, schedule, KPI and operational state. Do not create a parallel tracker.

Tool choice is outcome-driven: use the minimum useful combination, and combine tools when that produces a materially better asset.

## Trend tests — maximum 3 active

### T1 — Diagnostic vertical video
Format: 20–35 second 9:16 video.
Structure: problem hook in first 1–2 sec → 3 visual diagnostic cues → one actionable takeaway → soft CTA.
Visual language: greenhouse/irrigation/sensor imagery, closeups, clean subtitles, technical UI/data overlays.
Primary metric: retention / 3-second view rate, then saves/shares and qualified replies.

### T2 — Saveable diagnostic carousel
Format: 6–8 slides, 4:5.
Structure: strong technical question → symptom → cause → check → priority → CTA/checklist.
Visual language: editorial typography + annotated diagrams + minimal data cards; no generic stock-photo collage.
Primary metric: saves and shares.

### T3 — Human technical POV / Murcia field note
Format: 30–60 sec vertical video or voice-over B-roll.
Structure: one real local/agtech observation → why it matters → what BZ would inspect first.
Tone: practitioner, concise, non-corporate.
Primary metric: qualified comments, profile visits, DMs/conversations.

## Production-state discipline
Every meaningful asset should be in one explicit operational state in the Control Center or its linked production record:

**Idea → Research ready → Copy ready → Visual direction ready → Prompt ready → Asset ready → Draft → QA → Approved → Scheduled → Published → Archived**

Do not create a second spreadsheet merely to track creative states. “Almost done” is not a state; record the actual blocker.

## Measurement plan
Until there are at least 8–12 comparable organic pieces across multiple formats, avoid hard conclusions.

Track by format:
- static/carousel: reach, saves, shares, meaningful comments, profile/site actions;
- Reel/short video: views, 3-second view rate, retention, average watch time, saves, shares, follows from post;
- lead/B2B: DMs, qualified conversations, calls/meetings, partner interest.

Decision rule: keep the core brand stable. Iterate hook, framing, pacing, subject and CTA using repeated evidence, not one-post outcomes.
